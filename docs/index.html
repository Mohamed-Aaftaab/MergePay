How it works

How it works

  1. Fund a pool

    Send USDC to the contract for one repository. You set the most a single pull request can earn and the date the pool closes. Whatever is left after that date goes back to you.

    Testnet funding transaction

  2. Merge with a pay label

    A workflow in your repository reads the label, asks GitHub for a signed token that names the pull request, its author and the amount, and sends it to the contract.

    Workflow run for PR #1

  3. The author is paid

    The contract checks GitHub's signature and pays the NEAR account the author linked. If they haven't linked one yet, the award waits for them.

    Payout transaction
