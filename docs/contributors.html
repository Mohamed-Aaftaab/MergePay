Contributors

Who gets paid, and where.

Each contributor tied their GitHub account to a NEAR account with a token GitHub signed for them. Only a newer token of their own can change it.

Check a payout account

Enter a GitHub username to see which NEAR account its payouts go to.

Link your account

  1. Copy link.yml into any repository you own.
  2. Run it from the Actions tab with your NEAR account and .
  3. Submit the token it prints with the contract's link method.

Awards made before you link are held, and paid the moment you link.
